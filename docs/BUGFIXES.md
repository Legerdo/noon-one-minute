# 수정한 버그와 개선 목록

## 플레이 피드백으로 수정한 것

| # | 증상 | 원인 | 수정 |
|---|---|---|---|
| 1 | 클리어 후 **이어하기** 하면 꼭대기의 녹슨 대진자가 이미 죽어 있고 할 일이 없음 | 처치한 적을 맵에서 지우는 규칙이 보스에도 적용됨 | 대진자는 클리어 후에도 남아 재대결 가능(보상 없음). 할아버지는 깨어난 모습과 새 대사로 바뀜 |
| 2 | 작업대 강화 시 **확인 창이 보이지 않음** | 확인 창(depth 1500)이 강화 패널(depth 2500) 뒤에 그려짐 | 확인 창을 모든 오버레이 위(depth 4000)로 올림 |
| 3 | 강화 화면의 **레벨 표시가 알아보기 어려움** | 작은 글씨 "Lv1"이 이름 옆에 붙어 있음 | 굵은 "Lv.1/3"으로 바꾸고 최대 강화는 밝은 색으로 표시 |
| 4 | 장비가 하나도 없을 때 **장비 구성 메뉴를 닫을 수 없음** | 닫을 때 "장비를 하나 이상 챙겨야 한다" 검증이 항상 실행됨. 항목 0개일 때 커서 이동도 비정상 | 가진 장비가 없으면 변경 없이 닫힘. 안내 문구 표시, 빈 목록 입력 처리 |

## 플레이 피드백으로 개선한 것

- **첫 전투 안내(강제 선택)**: 처음 5번은 추천 장비 하나만 고를 수 있습니다. 추천 슬롯에 포커스와 화살표가 붙고, 나머지 슬롯은 흐려집니다. 똑딱이가 왜 그 장비인지 실제 계산 결과로 한 줄 설명합니다.
- **현재 목표 표시**: 탐험 화면에 "목표: …" 줄이 진행에 맞춰 바뀝니다.
- **연습 인형 먼저**: 태엽 쥐와 싸우기 전에 연습 인형과 한 번 겨뤄야 합니다. 첫 전투가 안내 전투가 됩니다.

## 개발 중 검증으로 찾아 고친 것

| 증상 | 원인 | 수정 |
|---|---|---|
| 전투에서 돌아오면 탐험 화면이 멈춤(`Cannot read properties of undefined (reading 'sys')`) | 장면을 다시 시작할 때 이전 실행에서 파괴된 맵 이미지를 재사용함 | 장면 초기화 때 참조를 비우고, 활성 객체일 때만 재사용 |
| 1층 동쪽의 금 간 벽이 보이지 않아 비밀방을 찾을 수 없음 | 옆벽 타일은 벽면 대신 벽 윗면으로 그려짐 | 금 간 벽은 위치와 관계없이 벽면(금 무늬)을 그림 |
| 1층 하단 통로가 방 경계 밖으로 새어 나감 | 맵 격자 한 줄의 벽 문자가 어긋남 | 격자 수정, 맵 도달성 테스트 추가 |
| 적 의도 말풍선이 공격 연출과 적 스프라이트를 가림 | 말풍선을 적 머리 위에 띄움 | 의도 표시를 시간 레일의 적 표식 옆으로 옮기고, 위험 동작은 무대 위 경고 표식으로 표시 |
| 진자 기사가 크게 휘두를 때 진자검이 잘림 | 스프라이트 캔버스 여백 부족 | 캔버스 여백을 늘리고 발 위치를 고정 |
| 적의 발이 무대 바닥선에서 떠 있음 | 원점을 캔버스 아래 끝으로 잡음 | 실제 불투명 픽셀의 맨 아래 줄로 원점을 계산 |
| 조건 반응 AI가 같은 수비를 끝없이 반복 | 반응으로 끼워 넣은 행동이 패턴을 진행시키지 않음 | 반응은 계획된 행동을 "대신"하고 패턴은 한 칸 진행(`DESIGN_LOCK` 반영) |
| 베기 궤적 연출이 일부 각도에서 사라짐 | 호의 각도 범위 계산이 -π/π 경계를 넘지 못함 | 각도 차이를 0~2π로 정규화 |
| 타이틀 부제가 배경 패널 뒤에 숨음 | 그리기 순서(depth) 오류 | 패널과 글자의 depth를 명시 |
| 슬롯 장비 이름이 칸을 넘침 | 긴 이름을 그대로 표시 | 슬롯 전용 짧은 이름(단검·장검·대망치 …) 추가 |
| 보스가 너무 빡빡함(보통 강화에서 앞보기 전략도 패배) | 밸런스 | 보스 체력 130 → 120, 밸런스 테스트로 재검증 |
